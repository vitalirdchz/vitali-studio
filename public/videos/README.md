# Dossier Vidéos Locales — Vitali Studio

Vous pouvez glisser vos fichiers vidéos directement dans ce dossier :
`public/videos/`

### Formats supportés :
- `.mp4` (recommandé, codec H.264 / AAC)
- `.webm`
- `.mov`

### Comment l'utiliser dans le panneau admin :
Si vous déposez par exemple `mon-clip.mp4` dans ce dossier, le chemin à renseigner dans le formulaire de Réalisation est simplement :
`/videos/mon-clip.mp4`

Le lecteur de votre portfolio le lira instantanément au format vertical 9:16 !
